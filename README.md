# cook-walden-rip

An interactive map of the IABA-owned section of Cook-Walden Capital Parks cemetery
(Pflugerville, TX) — plot-by-plot satellite overlay showing who is buried where, what's
reserved, and what's available to inquire about. Modeled on Chronicle's `.rip` cemetery
maps. Static site, zero hosting cost; currently a proof of concept to pitch to IABA.
